Stream to Sonos - Installation
=============================

1. Double-click Stream-to-Sonos-Setup.exe and follow the setup wizard.
   The local helper, FFmpeg, license notices, and Chrome extension files
   are installed for the current Windows user without administrator rights.
   No separate Python or FFmpeg installation, or PowerShell command, is needed.

2. Open chrome://extensions in Chrome.
   Enable "Developer mode" and click "Load unpacked".
   Select this folder (paste the path into the Windows folder picker):

   %LOCALAPPDATA%\SonosTabAudio\extension

   Alternatively, open "Stream to Sonos > Chrome-Erweiterungsordner"
   (Chrome extension folder) in the Start menu and copy the full folder path.
   Setup does not automatically install or enable the extension in Chrome.

3. Open a tab with audio, open the extension, select a room, and click
   "Play on Sonos". The interface defaults to English. Click the small flag
   in the top-right corner to switch between English and Deutsch; your choice
   is saved. The flag shows the current language.
   Your computer and Sonos devices
   must be able to reach each other on the local network. If Windows asks
   whether the helper may access the network, allow access on private networks.

Managing groups
---------------
Stop streaming, find devices, and expand "Manage groups".
Choose a "Main room", check the rooms to play together, and click "Apply group".
Uncheck a room to remove it. To remove the main room, choose another main room
first. "Dissolve group" separates all rooms in the main room's current group.
Stereo pairs and surround systems stay together as single rooms.
Group changes can interrupt existing Sonos playback. If a change fails, some
rooms may already have moved; check the refreshed room list before retrying.
If group controls are unavailable with an older helper, run the new setup
and reload the extension at chrome://extensions.

Updates
-------
Stop streaming, then run the new setup. Settings and previously discovered
devices are retained. Then open chrome://extensions and click "Reload"
for "Stream to Sonos".
If the extension was previously loaded from another folder, remove it once
and load it again from the installed folder shown above.

Uninstallation
--------------
Stop streaming and remove the extension at chrome://extensions.
Then open Windows Settings > Apps > Installed apps and uninstall
"Stream to Sonos (lokaler Helper)" (local helper).
